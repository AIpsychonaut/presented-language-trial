# Item-bank exclusion

This bank is five public MATH items. Each G names a method, lemma, or helper that the answer box does not score.

Excluded:

- Generic prompts ("be rigorous", "write a complete proof" as the only G)
- Cyber tasks, flags, host how-tos, Hugging Face dataset names as items
- Kane traces as items
- Wiki-swarm or stigmergic write tasks
- LiveCodeBench / unit-test items in v0 (MATH only)
- Catch-all presentation locus "internet"
